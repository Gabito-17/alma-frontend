# 🩺 ALMA – Sistema Web para Policonsultorios

**ALMA** es una aplicación web moderna y profesional desarrollada con [Next.js](https://nextjs.org) & [Nest.js](https://nestjs.com/), diseñada específicamente para la gestión integral de un policonsultorio. Ofrece una interfaz elegante, intuitiva y responsiva gracias a [Shadcn UI](https://ui.shadcn.com), y se conecta de forma eficiente a una API REST para ofrecer una experiencia fluida y dinámica tanto a profesionales de la salud como al personal administrativo.

---

## 🚀 Tecnologías Utilizadas

- ⚡ [Next.js](https://nextjs.org) — Framework React para aplicaciones modernas.
- 🎨 [Shadcn UI](https://ui.shadcn.com) — Componentes UI accesibles y estilizados con Tailwind CSS.
- 💨 [Tailwind CSS](https://tailwindcss.com) — Framework de estilos utilitario.
- 🖋️ [TypeScript](https://www.typescriptlang.org) — Tipado estático para mayor robustez.
- 🌐 API REST — Comunicación fluida con backend personalizado.

---

## 📦 Instalación y ejecución

1. **Clonar el repositorio:**

```bash
git clone https://github.com/Gabito-17/alma-frontend
cd alma-frontend
```

2. **Instalar dependencias:** dependiendo del gestor de paquetes

```bash
npm install
# o
yarn install
# o
pnpm install
# o
bun install
```

3. **Ejecutar el servidor de desarrollo:** dependiendo del gestor de paquetes

```bash
npm run dev
# o
yarn dev
# o
pnpm dev
# o
bun dev
```

4. Abre tu navegador en [http://localhost:3000](http://localhost:3000) para ver la aplicación en acción.
